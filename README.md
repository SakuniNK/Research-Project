Bibliometric Analysis in Finance: Identifying Research Trends and Gaps Using Text Mining
Project Overview
This repository contains a text mining approach to perform bibliometric analysis on research papers in the field of finance. The goal of this project is to identify research trends, emerging topics, and gaps in the financial literature using techniques such as Natural Language Processing (NLP), topic modeling, and citation analysis. By applying these methods, we aim to provide insights into the evolution of finance research and highlight areas where future studies could be directed.

Features
Text mining techniques to extract relevant data from academic papers
Identification of key research topics and trends in finance
Citation network analysis to identify influential papers and authors
Topic modeling using Latent Dirichlet Allocation (LDA)
Visualization of research trends and gaps
Analysis of research gaps based on the distribution of topics and citations
Technologies Used
Python: Primary programming language for text mining and analysis
Pandas: Data manipulation and analysis
NumPy: Mathematical operations
Matplotlib & Seaborn: Data visualization
NLTK & spaCy: Text preprocessing and NLP tasks
Gensim: Topic modeling (LDA)
NetworkX: Citation network analysis
